# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability
If you discover a potential security vulnerability in SATBot, please **do not** open a public issue.

Instead, please report security vulnerabilities directly to the maintainer:
- **Telegram Support**: [@mx767](https://t.me/mx767)
- **GitHub**: Submit a private report via [GitHub Security Advisories](https://github.com/topuniuz/SATBot/security/advisories).

We appreciate your efforts to disclose vulnerabilities responsibly and will coordinate a patch promptly.
